## Mode d'utilisation

### Mode A — DS existant
Tu as déjà un DS (Figma, Storybook, bibliothèque de composants). Renseigne les sections
Tokens et Composants avec tes vrais composants. `/pm-prototype` s'y conformera strictement.

### Mode B — Pas de DS
Ce fichier est vide ou partiel. `/pm-prototype` propose d'abord une liste de composants
de base, te la fait valider, puis s'y tient sur tous les écrans. En fin de session, il
peuple ce fichier avec ce qui a été utilisé — ton DS émerge au fil des specs.

**Laisser ce fichier vide = Mode B automatique.**
